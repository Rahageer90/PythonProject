# 🧮 Calculator App (PyQt5)

A simple and elegant desktop calculator built with Python and PyQt5. This application performs basic arithmetic operations and offers a user-friendly interface with styled buttons and a dynamic input display.

## 🚀 Features
- Perform basic operations: addition, subtraction, multiplication, division  
- Real-time expression evaluation using Python's `eval()`  
- Clear input field and delete last character  
- Custom styling with PyQt5 layouts and fonts  
- Responsive, resizable UI

## 🛠 Tech Stack
- **Language**: Python 3  
- **GUI Framework**: PyQt5

## 🧰 How to Run
1. Make sure Python 3 is installed on your system  
2. Install PyQt5 using pip:  
   ```bash
   pip install PyQt5
   ```
3. Run the script:  
   ```bash
   python calculator.py
   ```
